## Agent skills

### Issue tracker

Issues live as local markdown files under `issues/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix), recorded as a `Status:` line in each issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context, but kept under `docs/`: the glossary is `docs/GLOSSARY.md` (not the repo root) and ADRs are in `docs/adr/`. See `docs/agents/domain.md`.
